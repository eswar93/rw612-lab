# 03 - ML / MQTT telemetry

**Status:** idea.

Rough direction (will change):

1. Board publishes sensor data over MQTT (Wi-Fi).
2. A broker and database store the telemetry on my PC.
3. I train a small model on that data (and learn CUDA along the way).
4. Run the model, either on the board or next to it, and close the loop.

Pieces I want to learn: MQTT, a database, model training, deployment.
